# ⚡ GPU Waste Hunter

An AI-powered cloud cost optimization and waste-detection dashboard built for hackathons. **GPU Waste Hunter** scans cloud configurations to detect unattached resources and provide smart recommendations.

## 🚀 Features
* **Live Cloud Auditing:** Connects via Boto3 to inspect cloud resource configurations.
* **Gemini AI Insights:** Automatically analyzes resource payloads and provides human-readable optimization strategies.
* **Interactive Dashboard:** Built with Streamlit for a fast, modern, and responsive user interface.
* **Instant Reporting:** Allows users to export generated cost optimization reports with a single click.

## 🛠️ Tech Stack
* **Frontend/UI:** Streamlit
* **AI Engine:** Google Gemini API (`google-genai`)
* **Cloud SDK:** AWS Boto3
* **Language:** Python
